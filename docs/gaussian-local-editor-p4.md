# 本地 Gaussian 编辑 P4

日期：2026-09-26。状态：**产品集成代码与静态检查完成，运行验收未执行。** P1／P2／P3 回归也仍未运行；P0 证据不能替代正式页面鼠标／键盘、网络与长时验收。入口保持实验，不改普通浏览默认渲染器，不进入 P5。

## 入口与源身份

- `App → GeometryViewer → GaussianSplatViewer` 传递既有 Job、variant／asset role。正式“本地编辑（实验）”入口挂在原查看器内，不使用云分支承载本地编辑。
- 当前 Spark 同源进入／退出只创建、更新、释放编辑掩码和 Worker，不重新下载／解析 PLY，不新建 WebGL context。退出恢复原模型显示，不把编辑版当作原导航模型。
- 旧查看器或 K2 进入时先明确确认使用原始 SH3 PLY＋Spark；记住相机、串行释放旧实例，允许一次必要加载。无自动 LOD、降 SH、抽点或选择失败后穿透。
- 仅提供完整 normalized/arbitrary、SH3、1–3M count、有效 browser SHA 的导出入口。保留加载时的小型 metadata 文本；打开文档前重新取回并要求相同。文档须匹配 Job、variant／role、PLY／metadata 资产 URL、已加载导出声明的源 SHA 和 count；Worker 准备时再核对实际解码 count。
- 浏览器复用服务端发布的源哈希身份，不将“相同数量”当作全体行序证明，不声称本阶段新增了浏览器对整个 PLY 的流式 SHA 复算。服务端 P2 的实际源文件哈希、metadata 哈希、授权与每次提交核对不变；源行映射依赖 P0 已冻结的完整 ExtSplats 路径。
- 使用既有文档列表／创建／描述 API，用户选择已有文档或从原模型新建副本；打开后自动进入 P3 授权和基线读回，不要求连接云渲染。首次打开产品文档需要 CPU API 可达，不承诺完全离线启动；已有编辑中的断网恢复沿用 P3。
- 文档请求限时 60 秒。创建响应丢失不会自动重复 POST；界面要求刷新列表、核对并选中已创建文档。未确认创建结果前，本次面板不再次新建。

## 离开保护与生命周期

- App 的 Job 加载、variant、几何类型、证据视图切换，以及源资产变化的 manifest 更新，在改变源状态前调用同一实时离开门禁。取消后保留当前源与编辑内容，不在子组件卸载之后才询问。
- 普通同源刷新保留当前 variant，不重置到默认模型。延迟的旧 Job 刷新／导航响应不替换已经切换的新 Job；读取新 Job 的响应返回后才做离开检查，等待网络期间新增的修改也会被检查。自动轮询遇到会使活跃本地／云查看器换源的资产变化时暂缓应用，由显式刷新再处理，避免每秒反复询问或自动关闭编辑器。
- 查看器退出编辑、切 renderer、本地／云切换共用该门禁。未保存 visible、待确认请求或本地保护会提示先取消并保存／下载草稿；确认离开才放弃本地状态。选集与临时预览不单独算持久内容。
- 在途保存／文档操作时拒绝离开，避免把未结束的保存伪装为放弃。确认离开后禁用输入、取消选择，串行等待初始化／授权关闭／Worker／显示释放；关闭失败明确报告并停止切换，保留已持有状态供草稿下载，不吞错宣告成功。
- 同源退出等待 Spark 恢复原始显示；模型释放后才允许下一本地实例加载。跨本地组件卸载重挂也复用 Geometry 层释放 Promise，不靠组件私有 ref 遗忘旧实例。
- WebGL 渲染失败时不先销毁当前编辑面板和草稿状态；用户仍须处理保存／草稿再离开。原生 beforeunload 仍是尽力提示，不承诺防崩溃、关机或未经本组件控制的外部强制卸载。
- 云端加载／操作中或会话未关闭时拒绝切源／切本地，提示用户明确点击“关闭会话”；门禁不会偷偷 DELETE 或抢占远端会话。旧云选择、票据、预览和授权协议不变。

## 输入与布局

- 编辑使用宽工作区：左侧画布、右侧独立滚动面板；窄屏面板放到画布下方。不让保存、版本列表或错误信息改变正在选择的画布布局。
- 选择工具、范围、选集操作、删除、撤销／重做和保存／导出直接可用；保护、隔离、对照说明折叠。显示选中／保护／可删除数量与 P3 未保存状态。
- 进入时退出 Walk／pointer lock，编辑期间禁用漫游和调试碰撞显示；迟到的 pointer-lock 获取也被拒绝。退出时恢复原模型浏览后才恢复漫游能力，编辑结果仍为 `manual_edit_not_evaluated`／`not_inherited`。
- 本地编辑不请求 render-session、ICE、offer 或固定 PNG；服务端仅处理文档与 CPU 导出，生产 GPU／媒体服务配置不改。
