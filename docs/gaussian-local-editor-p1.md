# 本地 Gaussian 编辑 P1

日期：2026-09-24。状态：**P1 代码实现与静态检查完成，运行验收未执行。** P0 的历史准入证据不自动覆盖新增的高亮、普通框选、交互和历史代码。本阶段不启用正式产品入口，不提供保存／导出，不改旧云协议。

## 实现边界

- `LocalGaussianEditor.tsx` 是显式挂载的独立面板，参数为已加载的 `SparkPageViewer` 和对应原始 PLY 的 SHA256。现有 `App`／`GeometryViewer`／`GaussianSplatViewer` 没有新增入口，也不自动实例化编辑 Worker。P4 接入时必须从当前可信源元数据取得身份，处理切源和未保存提示，不能把任意字符串当作源校验。
- 复用同一 Spark 实例、相机、全量 SH3 ExtSplats；不重新下载或解析 PLY，不重建 WebGL context，不使用 K2、LOD 或降 SH。渲染仍在 WebGL，选择仍在 Worker；没有 Python／CUDA 热路径或云会话请求。
- 本阶段状态只在内存中；卸载面板会恢复纯查看管线并丢弃修改。面板明确提示没有保存与导出。退出保护、刷新恢复和正式产品切换保护分别留在 P3／P4，不冒称已完成。

## 选集与操作历史

`localGaussianEditing.ts` 使用 little-endian packed mask，源 ID 始终是原始 PLY 行号。区分 `visible`、`selected`、`protected`；输入输出掩码复制，不能通过调用方旧引用修改状态。

- 支持新建、追加、减选；空选集不能减选；隐藏行不能重新被选中。已完成选集跨相机移动保留。
- 隐藏作用域为 `selected ∩ visible ∩ 非protected`。实际移除数量超过当前可见数量的50%时，交互层显示确认；状态层再次校验。禁止全删，保护项不删除。
- 撤销／重做记录可见性和保护状态，最多100步及80MiB历史上限；新实质修改截断 redo，无效操作不占历史。3M 时101份双mask快照为75,750,000字节（约72.2MiB），不复制完整模型。该数不含当前掩码、Worker几何、渲染编码和其他浏览器内存，不是实测总内存。
- 选集和临时预览不进入历史；隐藏后清除选集中已隐藏的行，撤销恢复可见性但不自动恢复旧选集。
- 隔离、删除后预览和原始全保留对照只派生显示 mask，不写 `visible`。原始对照中禁止删除；返回编辑画面后才可再次选择。预览时关闭高亮，避免将叠色差异当作删除效果。
- 保护是当前编辑工作期的状态，不是持久物体锁。

## 选择与预算

`gaussianSelection.worker.ts` 继续使用同一个 Worker handler。原 `select` 请求保留 P0 默认128×128面积预算；P1 使用独立的 `select-local` 消息。所有模式均带源SHA、模型generation、相机generation和递增序号。

1. **表层（默认）**：复用P0椭圆投影与前向透明贡献，不用中心命中替代。P1允许包围矩形面积≤1,048,576实际绘图像素，按16×16瓦片遍历；100,000候选、8,000,000访问和2秒预算不变。大框可能因候选／访问／时间预算整体失败；此上限是代码边界，不是大框性能承诺。不降采样、不提交部分结果、不回退穿透。
2. **深度薄层／显式穿透**：移植Python `select_polygon` 的中心投影与边界命中；无遮挡判断，不包含可选保守球覆盖。深度为Three视空间的 `-z`，对应native相机的正深度；范围满足 `0.01 ≤ near < far ≤ 1e6`。穿透固定使用这一全范围。多边形3–128点、面积至少1绘图像素，视口各边≤4096；另设32M多边形边访问与2秒预算。
3. **三维盒**：移植 `select_box`，按源normalized坐标中的中心与闭区间轴对齐盒比较，同时排除已隐藏行，2秒预算。Three `TransformControls` 提供局部轴平移／缩放，不提供旋转；盒子的父节点携带源到显示的摆正矩阵，提交边界仍在源坐标中。
4. **薄层锚点**：显式点击一个实际绘图像素，只在P0前层判定可信时返回深度。低置信结果报错，不吸附后景；可手工输入近远端或改用盒选。由锚点生成的范围在相机变化后失效，须重新拾取或手工输入；已经完成的源ID选集不失效。

`tests/fixtures/gaussian_local_selection.json` 同时供TS与Python测试消费，包含旋转相机、穿透、深度闭区间及源轴盒金样。只是共享输入输出，不声称两种语言运行同一份算法。

## 显示、输入与生命周期

- `LocalGaussianDisplay` 复用P0的R8UI仅alpha mask，额外用独立RG8UI packed纹理高亮选中／保护项；高亮只改变生成的显示RGB，关闭后纹理清零，不写源几何、颜色或SH。源行位索引与隐藏一致，但新增着色器仍待真实GPU编译／画面验证。
- `SparkPageViewer.beginLocalEdit/updateLocalEdit/endLocalEdit` 与在途排序串行；几何提取、纹理更新和释放期间不并发启动Spark update。调用方合并待显示状态，不为每次输入无限排队。最终dispose等待加载、排序与编辑队列后释放资源。
- 矩形／套索用画布CSS尺寸映射到真实drawing-buffer像素；套索每移动至少2绘图像素追加顶点，最多128点；超出直接取消，不在超限后简化已有路径。拖选暂时禁用轨道更新，松开／取消／卸载恢复。Alt＋左拖或导航工具允许转动；完成选集不会要求固定PNG。
- Worker客户端负责取消等待者、响应身份核对、消息超时和terminate。交互层再核对请求时的编辑修订与相机矩阵／视口签名；移动相机、改工具、保护、隐藏、预览或卸载都不能应用旧结果。返回结果后仍会检查签名，不仅依赖下一帧观察器。
- Delete、Ctrl/Cmd＋Z、Shift＋Ctrl/Cmd＋Z、Ctrl/Cmd＋Y、Esc仅在画布或面板聚焦时处理；输入框、select、contenteditable、输入法组合状态不拦截文本操作。
- 矩形、套索、深度、保护与历史的UI已经连接独立控制器；三维盒使用已安装Three能力，没有新增库。组件生命周期串行处理异步打开／关闭，避免快速切源时旧清理误删新编辑资源。
