## 1. 输入匹配图不是八个分量

按 pinned COLMAP `8bac7b9` 的数据库装载默认规则核对：`min_num_matches=15`、`ignore_watermarks=false`。原 Mapper 请求未覆盖这两项。所有非空 verified 边恰好均满足至少 15 个对应，因此全 verified 图与 Mapper 边数门槛图相同。

|---|---:|
| 输入图像 | 446 |
| exhaustive 测试图像对 | 99,235 |
| 非空 verified 边 | 7,254 |
| verified 对应 | 1,842,314 |
| 连通分量 | **2：408 + 38** |
| 最大分量内主体注册 | 247 |
| 最大分量内未注册 | 161 |
| 孤立节点 | 0 |

补充只读定位：38 帧小分量是数据库 image ID 187–224，时间 **299.101–305.424 秒**；其中 `model_3` 注册 25 帧、`model_5` 注册 10 帧，均与主体无共同注册相机。其它六个模型均位于 408 帧大分量。

因此，八个输出模型不等于八个输入匹配图分量。38 帧确实没有通向其它输入的 verified 边；但大分量内部也存在大量注册失败，不能仅用全局连通分量数解释。

配置计数为 UNCALIBRATED（3）5,473 对、PLANAR_OR_PANORAMIC（6）1,774 对、WATERMARK（7）7 对。这是两视图估计标签，不是场景物理分类、真实误匹配率或全局可解性的证明。

## 2. 未注册帧缺少直接连接到主体三维点的支持

方法：从主体 `points3D.txt` 的完整 `(image_id, point2D_idx)` 轨迹建立索引；只读 Mapper 可用 verified 对应，寻找未注册图中的哪些二维关键点能直接关联到主体已有三维点。对多个邻居指向同一三维点去重，单独记录一个二维点对应多个三维点的歧义。

**这不是重新运行 PnP，也不是历史注册时刻的状态重放。** 它描述最终冻结主体能够提供的直接候选支持；没有验证内点、空间分布、相机参数条件或补充三角化后的潜力。

| 未注册区间 | 帧数 | 零候选二维点的帧 | 单帧候选二维点最大值 | 至少 30 个候选二维点的帧 |
|---|---:|---:|---:|---:|
| 前段 266.091–282.430s | 98 | 90 | 26 | 0 |
| 间隙 296.106–309.949s | 66 | 58 | 20 | 0 |
| 间隙 330.614–338.434s | 35 | 26 | 17 | 0 |
| 合计 | **199** | **174** | **26** | **0** |

两个内部间隙的正分特征数中位数分别为 551.5 和 320；前段则为 1,655.5。特征少与三维支持不足不是同一指标，不能把整个前段也归为没有二维特征。

pinned `incremental_mapper.cc` 在注册前检查 `NumVisiblePoints3D >= abs_pose_min_num_inliers`，默认最少 30；`observation_manager.h` 明确此量是“至少有一个对应连接到其它图中已三角化点的二维图像点数”。本次所有未注册图在最终主体上的直接候选二维点都少于 30，支持“当前主体缺少可用于继续注册的直接支持”，而不是“已有充足 PnP 内点却被求解器拒绝”。这不证明其它初始化、轨迹传播或求解顺序也不可能恢复。

## 3. 时间间隙两侧并非完全断开

主体中有 **3,423 条**三维轨迹跨越第一个内部间隙的两侧，**3,216 条**跨越第二个间隙的两侧；两处也都有直接跨越时间区间的 verified 边。

准确表述是：主体已经通过其它观测连接了间隙前后，却未能把中间这些图像注册进同一主体。此前“跨弱区支持不足”应细化为对具体未注册帧的支持不足，不能解读为两个间隙两侧各自完全孤立。

## 4. 局部模型仍有可审查的关系，但不能相加或直接合并

- `model_7`（42 帧）与主体共享 **9 张注册相机**，另含第一个内部间隙 19 帧、第二个内部间隙 14 帧。
- 前段 `model_1` 与 `model_2` 共享 20 张；`model_2` 与 `model_6` 共享 20 张，但它们都与主体无共同注册相机。
- `model_4` 的 11 张注册相机全部也在 `model_7` 中。

这里只统计同一数据库下的共同图像，不估计 Sim3、不验证共同相机的位姿一致性、不合并点云。共同注册图提供了后续相对几何一致性审查的入口，不是合并授权或正确性证明。

主体 23,753 条轨迹的独立图像数中位数为 8；首尾时间观测射线夹角中位数为 3.43°，254 条小于 1°；点平均重投影误差的中位数为 0.532 px。首尾夹角不是最大三角化角，不能将这些数值当作真值精度或排除全部几何退化。

**5,319/23,753（约 22.39%）主体轨迹在同一张图中包含多个不同关键点。** 没有完全重复的 `(image_id, point2D_idx)`。独立图像数与原始观测数分开统计：二者中位数都是 8，但 p90 为 24 对 26、最大值为 67 对 119。这个现象提示观测数不等于独立视角支持；本轮没有检查这些关键点的像素邻近性，不能直接判定为错误轨迹或新的 COLMAP 缺陷。

## 结论与后续边界

本轮把失败分成两种机制：

1. **38 帧的输入 verified 图确实与主体分量断开。** 保持同一匹配图仅更换求解器不能凭空创造跨分量约束。
2. **408 帧大分量虽连通，仍有 161 帧未加入主体；最终主体对全部未注册帧的直接三维支持均不足。** 连通性并不等于可注册性，继续只跑 `image_registrator` 不应被视为已有充分依据的恢复方案。

下一步优先建议是审查 `model_7` 与主体的九张共同相机及共同特征几何，判断这个局部模型是否提供一致的桥接证据；对真正断开的 38 帧，则需要先证明能新增可靠跨区对应，再讨论求解器。重复图像观测应以独立视角计数审视，不能用更长的原始 track 充当更强证据。
