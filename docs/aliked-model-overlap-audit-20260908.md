## 方法

1. 比较冻结主体 `model_0`（247 张注册相机）和 `model_7`（42 张）。九张共同图像全部参与一个无反射、正尺度、最小二乘 Sim3 拟合，不使用 RANSAC、不删异常点、不调阈值。
2. 使用同一个相似变换检查共同相机中心和朝向；逐张排除后用其余八张重新拟合，记录被排除相机的中心残差，以观察拟合敏感性。
3. 按同一数据库的 `(image_id, point2D_idx)` 找三维点对应，不能将两个模型内同号 point3D ID 当作同一个点。对多对一/一对多关联单独计数，并区分重复观测与独立共同图像支持。
4. 三维点残差只使用相机拟合的 Sim3，不另拟合点云来隐藏相机与点云不一致。没有执行 PnP、Mapper、BA 或原始 RGB 加载；逐张排除是对既有相机的诊断，不是 Test 划分评估。

逐张排除后，被排除相机的归一化中心残差最大为 **168.56%**（candidate 1859，309.949 秒）。主体共同中心的中心化奇异值为 `[2.066945, 0.204951, 0.045891]`，`model_7` 为 `[4.631421, 1.462438, 0.349399]`。主体中心接近线状分布，不能将中心拟合得到的旋转当作充分稳定的唯一对齐依据。

共有 1,783 个共同特征观测，对应 366 个不同三维点对；50 个主体点关联多个 `model_7` 点，77 个 `model_7` 点关联多个主体点。双向唯一点对为 175 个，其中 172 个至少被两张独立共同图像支持。限制到这 172 个点对后，大残差仍存在；这不是只由单图偶然关联或重复计数造成的表象，但仍不是真值误差评估。

## 结论边界

**共同注册九张图像，不足以把 model_7 当作已验证的桥接模型。** 当前全部中心拟合的一个 Sim3 不能同时使相机朝向和同特征三维点取得一致，因此本轮不支持直接将它的额外 33 张相机拼入主体来充当覆盖恢复。

这不是“model_7 已被真值判错”，也不是“任何其它对齐方法必然失败”的证明。共同轨迹时间范围窄、相机中心近线状、内参分别优化，都会限制仅依靠中心的相似变换审查。两模型原有 pose-health PASS 仍只是灾难级守卫通过，不能替代跨模型一致性。

后续若继续，应先区分对齐旋转的不确定性、自标定差异和真实结构冲突；本次没有运行朝向约束拟合、三维点独立拟合或固定内参求解。另一处 38 帧孤立匹配分量仍需新的可靠跨区约束，不能通过本次共享相机分析解决。
