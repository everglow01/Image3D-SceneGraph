# 三组原生日志只读分析

2026-10-27 · MCMC-B1-E007 · **只分析既有C0/C1/C2文本，没有联网、启动实验、读取图像或执行模型。**

## 结论

现有证据支持：**loss差异在迁移前已出现并逐渐变大；第一次迁移之后的100步中，组间差异明显更大且广泛存在，不是单个异常峰值或正则项造成的假象。** 但无法仅凭这些日志把放大归因于迁移、来源抽样、持续noise或某个owner。

本分析不改变正式结果：校准阻塞、U/O未运行、观察器未获准入、没有真实逐点Q1轨迹，不重算更宽的验收阈值。

## 1. 先对齐时间与比较对象

已对照协议绑定的冻结源码核验：trainer在每步依次进行渲染、loss计算、反向、Adam、策略/迁移/noise，之后才汇总并写日志。因此：

- 12100步loss是**第一次迁移之前**的渲染结果；12101步才可能含12100步迁移的影响。
- 12200步loss在**第二次迁移之前**计算；第二次迁移不能解释本次记录中的loss分化。
- `before_strategy_after_optimizer`健康计数则在本步Adam之后，和同一行loss不是完全同一时刻的状态。
- `render_intersections`描述all-to-all后的相机执行rank，不是该owner独占的点贡献；不能用它把loss归属到owner。

三组200步相机批次逐步相同，SH均为3、全局点数均为300万、每步原生noise保留，两个迁移事件均为12100/12200。总共400个图像ID没有重复：同一步跨run可配对，但跨步换了相机，不能将时间效应与视角敏感性彻底分离。

下文逐步差距定义为`R(t)=同一步三组reconstruction_loss的最大值−最小值`，各组在该步使用相同相机批次。它不同于准入使用的“各组20步平均loss之间的范围”；本文不拿R(t)替代原门槛。

## 2. 分化不是从迁移才开始

- 12001、12002步的记录loss相同。
- 第12003步首次出现记录差异：C0/C1为0.05114768072962761，C2为0.051147688180208206，范围约`7.45e-9`。
- C0与C1的记录loss从12004步起不同；SSIM首差12004步，两个正则项首差12005步。

这是**记录标量首次可见差异**，不证明参数、梯度在此前位级相同，更不能据此替换旧首步定位结果。

| 步段 | 逐步组间差距R的中位数 | R的平均值 |

| 12001—12020 | 3.054738e-07 | 8.5043721e-07 |
| 12021—12040 | 7.5255521e-06 | 1.3389951e-05 |
| 12041—12060 | 2.092775e-05 | 5.0592842e-05 |
| 12061—12080 | 6.9030561e-05 | 9.3515171e-05 |
| 12081—12100 | 0.0001300266 | 0.00028819037 |
| 12101—12120 | 0.0016677277 | 0.0023320077 |
| 12121—12140 | 0.0025831964 | 0.0030267628 |
| 12141—12160 | 0.0041115116 | 0.0092599611 |
| 12161—12180 | 0.0022499361 | 0.0038572703 |
| 12181—12200 | 0.0028870385 | 0.0045424981 |

首个迁移后20步的R中位数约为前20步的12.83倍。跨整个前/后100步，中位数分别为`2.1547e-5`与`0.00232730`，约108倍；这个倍数依赖分段，不能解释成迁移的因果效应或loss本身增长108倍。

边界并非整齐的单步跳变：12100、12101的R分别为0.00014305、0.00016928，12102才升至0.00168362；迁移前12096的R已达到0.00118793。不同相机在不同时间被观察，只能称“迁移前已有分化，迁移后所观察窗口更分散”。

## 3. 不是一个异常峰值撑起来的

- 迁移后100步中，**80步**的R超过迁移前100步最大值0.00123781。
- 最大峰值位于12144步、相机批次2218/3406：C0/C1/C2的loss为0.10473566/0.04736038/0.03766342，R为0.06707224。
- 最大峰值贡献后100步R总和的14.57%；最大的五步合计占32.37%。事后去掉这五步，剩余95步R中位数仍为0.00228783，接近未删时0.00232730。
- 最大峰值12144不在导致末端准入失败的12181—12200窗口内，不能解释成“就这一行把最后20步均值抬高”。

最大值排序与删点仅是标明为事后的敏感性描述，不是新门禁、不用于重判通过；没有独立重复视图，不能认定这些相机天然有问题。

## 4. 三对运行都分化，没有一条始终更好

| 配对 | 迁移前100步绝对差中位数 | 迁移后100步绝对差中位数 | 后100步左侧loss更低 / 右侧更低 |
|---|---:|---:|---:|
| C0-C1 | 1.1275522e-05 | 0.0013244902 | 51 / 49 |
| C0-C2 | 1.7712824e-05 | 0.001412834 | 52 / 48 |
| C1-C2 | 1.0588206e-05 | 0.0016156081 | 45 / 55 |

例如C0−C1在后100步的有符号均值只有0.00011457，而绝对差均值为0.00323516，说明不同相机批次上的差异会正负抵消。C1在最后20步均值最低，但后100步并非一直比另外两组低；不能把某一组认定为整体更优，更不能当作Validation质量提升。

## 5. 分化来自图像重建项，不是正则项改变了账面总loss

冻结公式为`reconstruction_loss = 0.8 × L1 + 0.2 × (1−SSIM)`，准入使用的正是该重建项，本来就不包括opacity/scale正则。

最后20步C0−C1平均重建loss差为0.00155904，其中：

| 分项 | 对该有符号差的贡献 |
|---|---:|
| 0.8×L1 | +0.00098161，约63% |
| 0.2×(1−SSIM) | +0.00057743，约37% |
| 两个正则项差之和 | −0.00000293，不计入重建项 |

两类图像项都参与差异；分项加和的残差处于浮点标量舍入量级。这里只排除“正则加到总loss里造成账面超限”，**不排除正则对优化轨迹的间接影响**；SSIM/L1也不能唯一定位到几何、颜色或可见性。

## 6. 与主线相关、但仍只到owner总量的证据

三组都呈现相同的owner总体不对称（下列是三组取值范围，不是误差条或置信区间）：

| 状态 | owner0死亡率 | owner1死亡率 |
|---|---:|---:|
| 12100策略前、Adam后 | 5.8542%—5.8590% | 11.2541%—11.2630% |
| 12100策略后 | 0.2459%—0.2578% | 0.8215%—0.8279% |
| 12200策略前、Adam后 | 6.3882%—6.4318% | 12.0873%—12.1457% |
| 12200策略后 | 0.2623%—0.2649% | 0.8671%—0.8780% |

即：**宏观owner不对称在三次运行里都保留了，但渲染loss仍会分化。** 12100迁移后死亡总数大幅下降，到12200策略前又上升；没有逐点映射，不能把新增死亡都称为“迁移目标复死”，更不能区分目标、来源、未参与点的责任。

四个健康采样状态中两owner的尺度零值/次正规值计数均为0；这仅表示这些采样点未见该特定异常，不证明窗口中从未发生，也不是几何稳定性证明。owner不能等同固定物理GPU故障。

## 7. 能说到哪里，下一步不做什么

当前最窄的事实链是：**迁移前已有可见分岔 → 第一次迁移后的观测窗口中，跨run图像表现更分散 → 但owner死亡总量的不对称方向仍一致。** 箭头表示时间顺序，不表示已经证明因果。

现有日志没有迁移源/目标逐点身份、逐步梯度、独立每相机loss或同一视角跨时间重复，不能区分抽样路径、持续noise、后续优化累积及视角敏感性。尤其不能把两相机平均loss的差异归给某个owner来源池。

至此已完成本轮现有日志能够支持的只读拆解。**没有跑新实验、没有修改参数、没有放宽门槛、没有启动观察器。** 若之后设计新验证，问题应聚焦这些尚未分开的因素，而不是再次验证“是否存在一点数值差异”；本次不自动实施任何新方案。
