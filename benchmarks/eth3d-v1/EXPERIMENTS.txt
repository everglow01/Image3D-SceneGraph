Interpretation and next action
------------------------------
Accuracy is strong at relaxed tolerances, while completeness is the limiting metric.
The immediate investigation target is the COLMAP registration gap (3 of 14 images), not
confidence or filtering thresholds. Do not compare a future experiment to B1 unless it
uses the same ETH3D scene, RGB-only reconstruction protocol, one camera-derived Sim(3),
official evaluator tolerances, and recorded seed/configuration.

Registration-gap diagnosis (B1)
-------------------------------
Evidence source:
outputs/benchmarks/eth3d-v1/pipes/colmap_vggt_points/reconstruction/
  colmap_vggt/database.db

All 14 images were feature-extracted and exhaustively matched. The three unregistered
images have substantial SIFT feature counts, so extraction is not the bottleneck:
- DSC_0637.JPG: 1744 features
- DSC_0646.JPG: 3366 features
- DSC_0647.JPG: 3049 features

Their verified two-view geometry is sparse and largely isolated from the 11-image model:
- DSC_0637.JPG: 136 inliers with DSC_0638.JPG, 60 with DSC_0645.JPG; all other
  registered-image pairs have zero verified inliers.
- DSC_0646.JPG: 88 inliers with DSC_0643.JPG; all other registered-image pairs have
  zero verified inliers.
- DSC_0647.JPG: 109 inliers with DSC_0643.JPG, plus 25 or fewer with several images.

COLMAP first built the 11-image component, then initialized a separate component using
DSC_0647.JPG and DSC_0646.JPG. It attempted to add DSC_0643.JPG to that component twice
and failed, then found no further viable initial pair. The chosen output remains the
11-image component (1146 sparse points, 0.749424 px mean reprojection error).

Conclusion: the immediate failure is insufficient verified geometric connectivity between
these three images and the main SfM component, not lack of image features. The next B2
experiment must vary only COLMAP matching/registration settings while holding VGGT,
fusion, RGB-only inputs, seed, and the ETH3D evaluation protocol constant.

B2 design — relaxed COLMAP absolute-pose registration
------------------------------------------------------
Hypothesis: B1's default COLMAP absolute-pose registration thresholds reject the weak,
but geometrically verified, bridges from DSC_0637.JPG, DSC_0646.JPG, and DSC_0647.JPG to
the main model.

Probe command (uses B1's frozen feature/match database; no VGGT or fusion run):
/usr/bin/colmap mapper \
  --database_path outputs/benchmarks/eth3d-v1/pipes/colmap_vggt_points/reconstruction/colmap_vggt/database.db \
  --image_path data/benchmarks/eth3d/pipes/images/dslr_images_undistorted \
  --output_path outputs/benchmarks/eth3d-v1/pipes/registration_probe_relaxed_mapper/sparse \
  --Mapper.abs_pose_min_num_inliers 15 \
  --Mapper.abs_pose_min_inlier_ratio 0.10

Only changed variables from B1 COLMAP defaults:
- Mapper.abs_pose_min_num_inliers: 30 -> 15
- Mapper.abs_pose_min_inlier_ratio: 0.25 -> 0.10

Probe outcome:
- One 14/14-image sparse model was produced.
- Sparse points: 1225, versus B1's 1146.
- Mean reprojection error: 0.779376 px, versus B1's 0.749424 px.
- All three formerly missing images are in the same 14-image model.

Decision: B2 is justified as a controlled registration-coverage experiment. Implement
these two explicit runner options, then rerun the complete COLMAP+VGGT+fusion pipeline
with no other configuration changes. The official ETH3D evaluation will decide whether
coverage gains outweigh any geometry-quality cost from the relaxed registration gate.

Cross-scene conclusion after pipes and terrains
-----------------------------------------------
The relaxed COLMAP absolute-pose thresholds are a conditional recovery strategy, not a
new global default. Use B2 only when the default reconstruction has an evidenced image
registration gap; on pipes it restored 3 missing views and materially improved F1, while
on fully registered terrains it slightly reduced strict-threshold scores. Future scenes
must evaluate B1 first and trigger B2 only if registration coverage is incomplete.
